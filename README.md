# 🛒 Projeto - Carrinho de Compras (Node.js)

Este é um projeto simples em Node.js que simula um **carrinho de compras de uma loja**, permitindo adicionar, remover, listar itens e calcular o total.

---

## 🚀 Funcionalidades

- ➕ Adicionar itens ao carrinho
- ➖ Remover itens do carrinho
- 🗑️ Deletar itens completamente
- 📦 Exibir o carrinho
- 💰 Calcular o valor total da compra
- ⭐ Suporte a lista de desejos (wishlist)

---

## 📦 Tecnologias utilizadas

- Node.js
- JavaScript ES Modules
- Programação assíncrona (async/await)
